You'll test the new card creation functionality of the page.

1. Close the "Try Mercury" modal by clicking on the down chevron icon, and go to the "Cards" page.
2. Click on the create card button.
3. Leave the cardholder name as it is, and set the card nickname to "Lunch Card" (I've provided it in the variables). Don't change any other fields, and click on the "Create Card" button.
4. Verify that the new card has been created, and that it ends in 0330.
